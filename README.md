# Refilwe's Digital Space

Create a modern, professional, responsive personal portfolio website for me, Refilwe Thando Tladi, that I can use for job applications and share directly with recruiters.

This website is also a practical project for my AI Development Skills programme. It must demonstrate that I can use AI-assisted development tools to create a functional, well-structured website while understanding the design and code decisions behind it.

The website must feel authentic to me, polished, and professional—not like a generic AI-generated portfolio.

IMPORTANT:
Do not invent qualifications, employment history, companies, job titles, achievements, contact details, or technical skills that I have not provided.
Use editable placeholders wherever information is missing.
Do not create or use an AI-generated picture of me.
Do not generate a fake profile photo, AI avatar, cartoon version, or fictional person.
Instead, use a tasteful professional placeholder, an elegant initials-based profile design using “RT”, or leave an image area empty so I can upload my own real photograph later if I choose.
